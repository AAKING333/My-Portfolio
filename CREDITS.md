# Credits & Asset Licenses

## About-section 3D robot head (`aboutRobot3d.js`, `robot.js`)

The robot head is **procedurally generated in code** with Three.js, using the
site owner's own robot design (rounded-box head, visor, capsule eyes, ear
modules and a spring antenna). It is the owner's original work, so there is no
third-party model, texture or license to credit. No model file is downloaded.

For this site the owner's full-body robot was adapted to a head-only version
with a graphite, titanium and violet palette.
